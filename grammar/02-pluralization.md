# Pluralization

**Status:** Official

## Overview

Luma Lina uses one general plural marker:

```text
di
```

`di` expresses plurality by being placed **after the word it pluralizes**.

The same marker is used with nouns, pronouns, and demonstratives.

Luma Lina does not create separate plural forms for different types of words.

---

## Basic Rule

The structure is:

```text
Word + di
```

Examples:

```text
maimai
```

= goat

```text
maimai di
```

= goats

The plural marker does not change the original word.

---

## Nouns

`di` follows a noun to make it plural.

```text
maimai di
```

= goats

The same rule applies to other nouns.

```text
[teacher] di
```

= teachers

```text
[student] di
```

= students

Words that have not been officially established are written in square brackets as placeholders.

---

## Pronouns

`di` can also follow pronouns.

### `Ei`

```text
Ei
```

= I / me

```text
Ei di
```

= we / us

### `Ao`

```text
Ao
```

= you

```text
Ao di
```

= you all

### `Sa`

```text
Sa
```

= he / she

```text
Sa di
```

= they

### `Nu`

```text
Nu
```

= it

```text
Nu di
```

= they / those things

The plural marker is the same in every case.

---

## Demonstratives

The same plural marker is also used with demonstratives.

```text
ti
```

= this

```text
ti di
```

= these

```text
ta
```

= that

```text
ta di
```

= those

This reuses the existing plural system rather than creating separate words for `these` and `those`.

---

## Possession and Pluralization

Pluralization can combine with the possession/relationship marker `de`.

The plural marker follows the pronoun:

```text
Ei di de
```

= our

The noun can then also be pluralized:

```text
Ei di de maimai di
```

= our goats

Structure:

```text
Ei di + de + maimai di
we/us + possession + goats
```

Each `di` applies to the word immediately before it.

---

## Multiple Uses of `di`

A sentence may contain more than one `di`.

Each occurrence applies to the word directly before it.

Example:

```text
ta di la ei di de maimai di
```

Meaning:

**Those are our goats.**

Structure:

```text
ta di

those

la

copula (is/are/am)

ei di

we/us

de

possession/relationship

maimai di

goats
```

The three occurrences of `di` have different local functions:

* `ta di` → those
* `ei di` → we / our
* `maimai di` → goats

The marker remains unchanged.

---

## Core Rule

The official pluralization rule is:

> **`di` is placed after the word it pluralizes.**

This applies consistently to:

* nouns
* pronouns
* demonstratives

The language does not require separate plural forms when `di` can express the meaning compositionally.

---

## Summary

| Singular | Plural      | Meaning       |
| -------- | ----------- | ------------- |
| `maimai` | `maimai di` | goat / goats  |
| `Ei`     | `Ei di`     | I / we        |
| `Ao`     | `Ao di`     | you / you all |
| `Sa`     | `Sa di`     | he/she / they |
| `Nu`     | `Nu di`     | it / they     |
| `ti`     | `ti di`     | this / these  |
| `ta`     | `ta di`     | that / those  |

**Official rule:** `Word + di` → plural form.
